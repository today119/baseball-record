# 탁구 리그전 크롤러

매치메이커 프로(`matchmaker-pro-90a1b` RTDB)의 **2-1 ~ 2-4 탁구수행평가** 대회에서
학생별 경기 득점을 긁어, 야구수행평가 앱의 「리그 득점 일괄 입력」에 그대로
붙여넣을 형식으로 뽑는다.

```bash
python3 탁구크롤러/crawl.py          # 화면 + out/ 에 저장
python3 탁구크롤러/crawl.py --quiet  # 파일만
```

## 나오는 것 — `out/`
| 파일 | 내용 |
|---|---|
| `요약.txt` | 반별 진행률 + 평균 득점 상위 5명 |
| `latest.json` | 학생 전원의 경기수·총득점·평균·환산점수 |
| `붙여넣기_N반.txt` | `이름:득점,득점,…` — 앱에 그대로 붙여넣는다 |

## 점수 환산 (2026-2학기 평가계획)
평균 득점 **9.0↑ 20 / 7.0~ 16 / 5.0~ 12 / 3.0~ 8 / 미만 4** (+ 퍼슨십 카드 최대 4장, 영역 20점 상한)

## 대회 ↔ 학급
`2-1 탁구수행평가`→1반 · `2-2`→2반 · `2-3`→3반 · `2-4`→4반 (`crawl.py` 의 `CLASS_OF`)

⚠️ RTDB 는 인증 없이 열려 있다. **읽기만** 하며 쓰지 않는다.
