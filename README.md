# ⚾ 야구 수행평가 기록

체육 수업용 야구(전원타격제) 경기 기록·집계 웹앱. 단일 HTML 파일.

**바로 쓰기 → https://today119.github.io/baseball-record/**

## 무엇을 하나
- **전광판** — 큰 팀 밴드·점수, 다이아몬드 주루, `1루타/2루타/3루타/홈런/아웃` 으로 득점·타점 자동 계산
- **조편성** — 자동 배정(남녀 고르게·번호순·무작위·실력 균등) 또는 **드래프트**(주장 지정 → 여학생 라운드 → 남학생 라운드)
- **라인업** — 그날 결석생 체크로 제외, ▲▼ 로 타순 조정
- **기록실** — 타율·이닝당 기여도 누적, CSV·구글시트 내보내기

## 경기 규칙
전원타격제. 아웃 카운트와 무관하게 **타순 한 바퀴를 돌면 공수교대**.
두 팀 인원이 다르면 남녀 비율을 유지하며 타석 수가 적은 학생부터 **중복 타자**를 넣어 타석 수를 맞춘다.
- 타율 = 안타 ÷ 타수 (중복 타석 포함)
- 이닝당 기여도 = (득점 + 타점 + 수비 아웃 참여) ÷ 참여 이닝

## 구글 시트 구조
탭 하나 = 학급 하나(`1반` `2반` …). 명단과 기록이 한 표에 들어간다.

| A | B | C | D | E~R |
|---|---|---|---|---|
| 번호 | 이름 | 성별 | 조 | 경기·이닝·타수·안타·타율·득점·타점·수비아웃·이닝당기여·탁구·태도카드·보고서·갱신일시 |

앞 4칸은 명단(직접 입력 가능), 뒤는 앱이 채운다. 내보내기는 번호·이름으로 학생을 찾아 **E열 이후만** 갱신하므로 시트에서 손본 명단은 지워지지 않는다.

## 저장
- 기본은 **이 기기(localStorage)** 에만 저장 — 설정 없이 바로 쓸 수 있다
- **Firebase Realtime Database** 설정을 넣으면 여러 기기가 같은 경기를 실시간으로 나눠 기록한다 (타격 1회당 0.4KB 이하만 전송)
- **구글 스프레드시트** 는 명단 가져오기와 최종 성적 내보내기에만 쓴다 (경기 중에는 호출하지 않는다)

`야구_앱스크립트_브릿지.gs` 설치법은 파일 맨 위 주석 참고.
